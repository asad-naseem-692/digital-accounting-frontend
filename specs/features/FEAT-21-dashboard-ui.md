# Feature: Main Dashboard (UI)
**Owner:** Frontend | **Module:** Reports & Dashboard

## Goal
Give the user an at-a-glance view of their business's financial health
the moment they log in.

## Scope
- Page: `app/(dashboard)/page.tsx`
- Stat cards: Cash in Hand, Total to Receive, Total to Pay, Today's
  Cash In/Out, Unpaid Invoices count, Low Stock count (from FEAT-28).
- Quick-action buttons: Add Party, Add Cash Entry, Create Invoice.
