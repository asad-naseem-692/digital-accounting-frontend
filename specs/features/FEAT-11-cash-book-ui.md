# Feature: Cash Book (UI)
**Owner:** Frontend | **Module:** Cash Book

## Goal
Let a user log and review daily cash movement.

## Scope
- Page: `app/(dashboard)/cash-book/page.tsx`
- "Cash In" / "Cash Out" quick-entry buttons with amount, category,
  description, date fields.
- List of entries with running cash-in-hand balance shown per row.
- Top stat card: current cash-in-hand (from FEAT-16).
